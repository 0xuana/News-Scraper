# Implementation summary

Added extraction of a non-empty, closed `【title】` prefix from cleaned Aigupiao content. The extracted value is stored in the news model and PostgreSQL `title` column, while the prefix is removed from the canonical body and `raw_json.content`. Added regression coverage for valid titles, title-only content, empty brackets, non-leading brackets, unclosed brackets, and repository parameters.

# Requirement content

Extract `title` from the text between the leading `【` and `】` in cleaned news content. For example, `【恒指跌0.73% 恒生科技指数跌0.76%】港股午间收盘，恒生指数跌0.7` has the title `恒指跌0.73% 恒生科技指数跌0.76%`. Remove the extracted title prefix from stored content. Do not treat non-leading or unclosed brackets as a title.
